# Rapid Fire review: p3-calcium

Deck: content/rapid/p3-calcium.json. Source: KDT8 ch24 (textbook, all facts) plus RR5 p36-40 (Pharma Rapid Revision 5e OCR, osteoporosis page range, used only for added exam points; the page range is the closest available since the OCR file covers 5 PDF pages). Sarkar and Prep OCR had no further calcium content.

Cards: 265 (34 class). Ids rf-p3-calcium-0001 to 0268, with gaps where cards were removed.

## Corrections and omissions
- Teriparatide dose: KDT8 ch24 prints "20 mg" once daily s.c. Web check (Drugs.com, DailyMed) gives 20 mcg, and the book's own vial (750 mcg/3 mL) agrees. No owner book in the OCR gives the dose, so the dose card was omitted (no card written with the wrong figure).
- Removed from deck (not grounded in a clear reading): two bone-turnover class cards (influences that increase / decrease bone resorption). The table headers in KDT8 ch24 are garbled in the text extraction, so the direction of each agent could not be confirmed.
- Not carried over: Romosozumab (RR5 OCR reads "serostin", illegible).
- Not carried over: bisphosphonate relative potency numbers (KDT8 table columns garbled in extraction).
- Not carried over: calcitriol brand and unitage lines, and brand-name lists (not exam facts).
